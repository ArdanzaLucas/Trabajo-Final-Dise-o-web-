El proyecto

🎮 Temática

Elegimos los videojuegos free-to-play porque es un tema que nos gusta a todos y porque la API trae capturas reales de cada juego, ideales para cards visuales.

La idea es una “sala de arcade”: fondo oscuro con luces de neón, como las máquinas de los fichines.

🎨 Decisiones de diseño

  • Paleta neón: cian y magenta sobre azul casi negro, el look típico gamer.
  • Orbitron para títulos (estética retro-futurista) e Inter para el texto, que se lee bien en pantallas chicas.
  • Cards con bordes redondeados, etiqueta de género y un hover que las eleva y enciende un brillo cian.
  • Imágenes en 16:9, el formato original de las capturas, para que no se deformen.

🌐 La API

Usamos la FreeToGame API: pública, gratuita y sin registro ni API key.

  • Endpoint: https://www.freetogame.com/api/games
  • Devuelve el catálogo completo en un solo fetch (el JSON ya es el array).
  • Campos usados: thumbnail, title, genre, platform, short_description, publisher, release_date, game_url.

⚙️ Detalles técnicos

  • HTML5 semántico: header, nav, main, section, article, aside y footer.
  • CSS mobile first con variables en :root y 3 breakpoints: base 320px, 768px y 1024px. El grid de cards pasa de 1 a 2 y a 3 columnas.
  • Fetch con async/await y try/catch: muestra un spinner mientras carga, las cards si sale bien y un mensaje con botón “Reintentar” si falla.
  • Las cards se crean con document.createElement y textContent. Primero se muestran 6 y el botón “Cargar más” agrega de a 6.
  • Filtro por género: las opciones del select se arman a partir de los datos de la API y el filtrado se hace con filter() sobre la lista ya descargada, sin volver a llamar a la API.
  • El formulario se valida en el evento submit, con alerts específicos para cada error y reset() después de un envío correcto.
const respuesta = await fetch('https://www.freetogame.com/api/games');
const juegos = await respuesta.json();   // el JSON ya es el array
renderCards(juegos.slice(0, 6));          // mínimo 6 cards
